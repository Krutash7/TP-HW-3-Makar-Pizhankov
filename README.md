# Технологии програмирования. Финальное домашнее задание №3. Docker. Bash

Проект представляет собой автоматизированную систему генерации и анализа CSV-данные с помощью разных Docker-контейнеров.

---

## Инструкция по запуску

Перед запуском скрипта убедитесь, что у него есть права на исполнение:
```bash
chmod +x run.sh
```

### 1. Генерация данных
```bash
./run.sh build_generator   # собрать образ для контейнера генератора
./run.sh run_generator     # запустить контейнер, который сгенерирует data/data.csv локально
```

### 2. Анализ данных и генерация отчета
```bash
./run.sh build_reporter    # собрать образ для контейнера аналитика
./run.sh run_reporter      # запустить контейнер, который сгенерирует html отчет локально в директории data
```

### 3. Локальная отладка генерации (без Docker)
```bash
./run.sh create_local_data # в директории local_data создает data.csv (для локальной отладки)
```

### 4. Вспомогательные системные команды
  ```bash
./run.sh structure # Выводит структуру всех файлов и директорий проекта начиная с текущей папки
./run.sh clear_data # Очистка сгенерированных файлов
  ```
* **Проверка видимости данных изнутри контейнеров:**
  ```bash
  ./run.sh inside_generator 
  ./run.sh inside_reporter
  
  ```
